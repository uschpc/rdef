# Definition files for R containers

This repo stores a collection of container definition files for R, the programming language and environment for statistical computing and graphics. Use the definition files with Apptainer or SingularityCE to build R containers for use on Linux workstations and clusters. The target output is a Singularity Image Format (SIF) container (for x86-64 CPUs). The files are intended as templates that can be modified as needed. There are different variants for different use cases.
